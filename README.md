# e-plantShopping

## Paradise Nursery – Online Plant Shopping Application

### Project Overview

Paradise Nursery is an online plant shopping application developed using React. It allows users to explore different varieties of houseplants, view plant details, and purchase their favourite plants through a shopping cart.

### Features

- Attractive landing page with a background image.
- Navigation between Home, Plants, and Cart pages.
- Multiple plant categories.
- Plant images, descriptions, and prices.
- Add to Cart functionality.
- Shopping cart with quantity management.
- Increase and decrease plant quantities.
- Remove plants from the shopping cart.
- Automatic calculation of item subtotals and total cart amount.
- Continue Shopping and Checkout options.

### Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Redux Toolkit
- React Redux
- Vite
- Git and GitHub

### Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/aakankshabhatkar24/e-plantShopping.git
   ```

2. Navigate to the project directory:

   ```bash
   cd e-plantShopping
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

### Build

To create a production build:

```bash
npm run build
```

### Project Objective

The objective of this project is to develop a functional online plant shopping application while applying React components, React Hooks, Redux state management, and dynamic rendering.
